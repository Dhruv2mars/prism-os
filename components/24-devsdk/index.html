Build for a display you look through.

A Prism app is a web app that runs in a sandbox with no origin, no host DOM and no capability it did not declare. Everything it needs from the glasses it asks for, and the wearer can always say no.

Two files: manifest.json and your entry HTML. No build step, no bundler, no account to write your first one.

The sandbox

        
Your app is embedded with sandbox="allow-scripts" and deliberately without allow-same-origin. That gives it an opaque origin. It is worth knowing exactly what that costs you, because the failures are quiet ones.


        

          
You do not haveUse instead

          
            
localStorage, sessionStorage, cookies, IndexedDBprism.storage — a per-app store held by the host. One app can never read another's.

            
fetch() to the networkprism.fetch(url) — brokered, and refused unless the wearer granted network.

            
Access to window.parent or the host DOMNothing. The host is reachable only through the SDK's message channel.

            
<script type="module"> from the originClassic scripts. An opaque origin turns every module fetch into a CORS request, and it will fail silently. This is the single most common first-hour mistake.

            
Control of your own window sizeNothing to do — the OS measures your <body> and sizes the window to your content, clamped so the world stays visible behind you.

            
An opinion about text size or motionThe system pushes the wearer's settings in. Style against var(--a11y-scale) and [data-reduced-motion] on <html> and you inherit accessibility for free.

Validated at install, never at launch. The wearer should never install something that fails in their face later, so every rule below is enforced before an app is ever on the device.

Permissions

        
Declare only what you use. A capability missing from the manifest is refused before the wearer is ever asked — the OS will not widen your contract at runtime. High-risk permissions require a reason in your own words; the wearer sees it next to the system's explanation and is never asked to trust your copy alone.

Error codes

        
Every rejection from the SDK is a PrismError with a code. Branch on the code, never on the message — messages are wearer-facing copy and will be rewritten.

    Submit for review
    
        
    Review is a person plus the same automated checks you can run yourself. Nothing in the list below is a surprise at submission time — run the validator and Developer Mode first and you will already know the answer.
    

        
      
          
    1. 
            
      Validate
      
            
      Your manifest must pass with zero errors. Warnings do not block submission, but every warning is a line a reviewer will ask you about.
      
          
      2. 
          
    2. 
            
      Run it in Developer Mode
      
            
      Launch, suspend, resume, kill, go offline, and deny every permission you request. A reviewer will do all six. An app that dead-ends on a denial is the most common rejection.
      
          
      3. 
          
    3. 
            
      Submit the folder
      
            
      Your app folder is the package: manifest.json, your entry HTML, and any assets, all relative. No remote entry point is installable.
      
          
      4. 
          
    4. 
            
      Automated review
      
            
      Manifest validation, a sandbox launch, a permission-denial sweep, an offline pass, and a render at 310% text. Results come back in minutes with the failing screenshot attached.
      
          
      5. 
          
    5. 
            
      Human review
      
            
      One reviewer wearing the hardware. They judge glanceability and whether the permissions you ask for match what the app actually does. A reason that does not survive being read out loud is a rejection.
      
          
      6. 
        
    

        
    
          The catalog is at Apps.
          That is the wearer's view of the same package — what they see before installing, what they are asked to grant, and how they take it back.
